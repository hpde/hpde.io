ICON Extreme Ultraviolet Daytime Oplus Images

Edelstein, J. (2026). ICON Extreme Ultraviolet Daytime Oplus Images [Data set]. Space Physics Data Facility.

ResourceID
spase://SMWG/NumericalData/ICON/EUV/L3/Climatology-Daytime-Oplus/P10D

Description

ICON Daytime Oplus climatology. In this, 48-day windows of data
from the L2.6 v03 product are collected into regular altitude, longitude, latitude, and local time bins.
Uncertainty weighted mean and standard deviations of each parameter are reported in this file.
Note that NMF2 and HMF2 data do not have an altitude component, OPLUS data has an altitude component.
This single file spans the whole mission
