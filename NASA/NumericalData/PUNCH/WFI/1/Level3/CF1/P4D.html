FITS Extension #1 Data Array
Description

PUNCH Level 3 unpolarized F-corona model derived from WFI-1 observations and represented in the PUNCH mosaic coordinate frame. The data are stored as a compressed 4096 by 4096 floating-point image. The image uses helioprojective longitude and latitude coordinates with an ARC projection and a pixel scale of 0.0225 degrees, or 81 arcsec, at the reference point. The nominal wavelength is 530 nm. The reference time of the model is specified by the DATE-OBS FITS keyword.

FITS Extension #2 Uncertainty Array
Description

Reciprocal fractional uncertainty associated pixel by pixel with the WFI-1 clear F-corona model in FITS extension 1. The stored value is the model intensity divided by its absolute uncertainty. The array size is 4096 by 4096 by 1.
