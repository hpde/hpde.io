Description

PADRE MeDDEA Level0 Photon FITS data are uncalibrated hard X-ray event data obtained by the Measuring Directivity to Determine Electron Anisotropy (MeDDEA) instrument on the Solar Polarization and Directivity X-Ray Experiment (PADRE) CubeSat observatory. The Level0 photon files contain the same photon event data as the raw MeDDEA binary data, but converted to FITS format for more convenient analysis. Each raw photon data file generates a single Level0 photon FITS file. The photon product is an on-demand X-ray photon list that is generally available during large flares and calibration periods. Level0 photon files contain event data from detector triggers, including packet-level timing information and science event information such as detector identifier, channel, clock value, and uncalibrated event pulse height in ADC counts. These data support investigations of the directivity of solar flare hard X-ray emission and the angular distribution of flare-accelerated electrons.

Description

FITS extension 1, named SCI, is a binary table containing one row for each detected photon event. Each row provides the packet sequence number, event clock, ASIC, electronic channel, uncalibrated pulse height in ADC counts, baseline, packet time, packet subsecond clock, and detector pixel identifier.

Name
Photon Packet Data, FITS Extension 2
ParameterKey
PKT
Description

FITS extension 2, named PKT, is a binary table containing one row for each telemetry packet. The table contains packet timing and acquisition information, instrument status and data-quality values, and packet-level event summary quantities. Its columns are seqcount, pkttimes, pktclock, pktlength, livetime, inttime, flags, decim_lvl, drop_cnt, int_time_flag, num_hits, rate, and corr_rate.
