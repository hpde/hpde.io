Description

GOES-11 Solar X-ray Sensor (SEM/XRS) science-quality Level 2 daily solar X-ray background and average irradiance product (bkd1d), provided as a full-period NetCDF file. XRS-A covers 0.05-0.4 nm and XRS-B covers 0.1-0.8 nm. The product contains daily background irradiances, daily mean irradiances, quality flags, and daily average coverage fractions for both channels. Science-quality irradiances are retrospectively reprocessed using updated calibration and are not reduced by the historical operational scaling factors of 0.85 (XRS-A) and 0.70 (XRS-B). Consult the NOAA GOES 8-15 XRS Science-Quality Data ReadMe for processing methods and caveats.

Description

Daily background solar X-ray irradiance for XRS-A (0.05-0.4 nm). The background is derived from one-minute average measurements using hourly means in three 8-hour blocks.

Caveats
A systematic calibration discrepancy remains between GOES-8 through GOES-15 XRS-A (short channel) irradiances and GOES-R XRS-A irradiances. The GOES-16/GOES-15 XRS-A ratio is approximately 1.34; this comparison is not a universal per-satellite correction factor. Evidence suggests that GOES-R calibration is more accurate.
