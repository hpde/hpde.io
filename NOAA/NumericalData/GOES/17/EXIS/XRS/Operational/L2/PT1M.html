GOES-17 EXIS/XRS Operational Level 2 1-minute Average X-ray Irradiance

Machol, Janet; Codrescu, Stefan; Viereck, Rodney (2018). GOES-17 EXIS/XRS Operational Level 2 1-minute Average X-ray Irradiance [Dataset]. NOAA National Centers for Environmental Information.

ResourceID
spase://NOAA/NumericalData/GOES/17/EXIS/XRS/Operational/L2/PT1M

Description

GOES-17 EXIS/XRS operational Level 2 1-minute average X-ray irradiance (avg1m) product in daily NetCDF-4 files. The product provides one-minute averages of corrected primary-channel and individual-detector XRS-A (0.05-0.4 nm) and XRS-B (0.1-0.8 nm) fluxes, along with uncorrected observed fluxes and estimated electron contamination contributions. It includes the number of valid samples contributing to each average, quality flags and flags for excluded samples, primary channel information, corrected XRS-B2 quadrant currents, electron-correction status and spacecraft ancillary data. This operational processing stream is distinct from the retrospectively reprocessed science-quality Level 2 product. NOAA cautions that operational Level 1b and Level 2 data, particularly during early mission periods, may contain uncorrected issues and should not be used for scientific analysis. Consult the XRS Level 2 ReadMe and User Guide for details.

Description

One-minute average solar X-ray irradiance in the XRS-A band (0.05-0.4 nm), using the XRS-A primary-channel merged signal. Electron contamination estimated using GOES SEISS/MPS-HI has been subtracted: xrsa_flux = xrsa_flux_observed - xrsa_flux_electrons. Name
Flags for electron contamination correction
ParameterKey
electron_correction_flag
Description

Bit-field status of the GOES SEISS/MPS-HI-based electron contamination correction. The electron correction is valid when its status bit indicates 0 and invalid when the invalid-status bit is set (value 1). The interpolation flag (value 2) indicates short gaps in SEISS/MPS-HI data. The decay flag (value 4) indicates the correction is smoothly turned off over approximately 2 hours when SEISS/MPS-HI data are missing and a future value is unavailable; the correction is marked invalid after 1 hour of decay. Channel-specific significance flags (values 8, 16, 32, 64, 128, and 256 for XRS-A, XRS-B, A1, A2, B1, and B2, respectively) indicate that the estimated electron contamination exceeds 50% of the observed signal. Interpret combined flags using NetCDF flag_masks, flag_values, and flag_meanings.
